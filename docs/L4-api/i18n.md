# L4 — `src/i18n.py`

Bilingual block DSL. Every helper returns an HTML string containing both a `lang="zh"` and a
`lang="en"` variant (except `esc`).

## Inline
- `esc(s: str) -> str` — HTML-escape `& < > "` (wraps `html.escape(s, quote=True)`).
- `t(zh: str, en: str) -> str` — `<span lang="zh">…</span><span lang="en">…</span>`. For use
  inside shared containers (`th`/`td`/`li`/`summary`), **not** inside a block helper.

## Text blocks
- `lead(zh, en)` — lead paragraph pair (`<p class="lead" lang=…>`).
- `p(zh, en)` — paragraph pair.
- `h2(zh, en)`, `h3(zh, en)` — heading pairs.

## Cards
- `card(zh, en, kind="note", tag_zh=None, tag_en=None)` — callout card; `kind` ∈
  `{note, tip, important, analogy}`. Custom tag via `tag_zh`/`tag_en`.
- `analogy(zh, en)` / `note(zh, en)` / `tip(zh, en)` / `important(zh, en)` — `card` shortcuts.
- `highlight(zh, en)` — design-highlight card (💡), styled as `tip` with a custom tag.

## Rich blocks
- `code(src, lang="python", cap_zh=None, cap_en=None)` — code block. Python is syntax-
  highlighted via stdlib `tokenize`; other `lang` is escaped only. Optional bilingual caption
  wraps the result in `<figure class="code-fig">`.
- `table(headers, rows)` — `headers: list[(zh, en)]`, `rows: list[list[(zh, en)]]`.
- `accordion(sum_zh, sum_en, body, num=None)` — `<details>` with bilingual summary; `body` is
  pre-rendered HTML; optional numeric badge.
- `keypoints(items, title_zh="✅ 关键要点", title_en="✅ Key takeaways")` —
  `items: list[(zh, en)]`.
- `source_map(items, title_zh="🔬 源码对应", title_en="🔬 Source mapping")` —
  `items: list[(file, zh_desc, en_desc)]`.

## Glue
- `blocks(*parts: str) -> str` — concatenate rendered strings.

## Internal (underscore)
- `_highlight_python(src)`, `_highlight(src, lang)`, `_line_starts(src)` — the tokenize-based
  highlighter. `_line_starts` splits on `"\n"` only (to match `tokenize`'s line model).
- `_CARD_TAGS` — default `(zh, en)` tag labels per card kind.

`__all__` exports only the public helpers (module imports like `tokenize` are excluded).
