消息系统Messages

AgentScope 用结构化的消息对象承载对话。一条 Msg 记录「谁说的」（name + role）和「说了什么」——内容是一个内容块列表（下表详列各类型）。

AgentScope carries dialogue in structured message objects. A Msg records "who spoke" (name + role) and "what was said" — the content is a list of content blocks (the table below lists the types).

🧩 生活类比🧩 Analogy
把 Msg 想成一个信封：信封上写着寄件人与身份（name/role），里面可以装好几张卡片（内容块）——一张是文字，一张是图片，一张是「我要调用某工具」的请求。
Think of a Msg as an envelope: the outside shows the sender and role (name/role), and inside are several cards (content blocks) — one text, one image, one "please call this tool" request.

消息家族

The message family

Msg 是核心数据类。UserMsg、AssistantMsg、SystemMsg 是工厂函数，分别构造带固定 role 的 Msg（不是子类）。

Msg is the core data class. UserMsg, AssistantMsg and SystemMsg are factory functions that each build a Msg with a fixed role (they are not subclasses).

内容块

Content blocks

块类型Block type用途Purpose
TextBlockTextBlock普通文本plain text

ToolResultBlockToolResultBlock工具执行的返回结果the result of running a tool
DataBlockDataBlock多模态数据（图片/音频等，含 Base64Source / URLSource）multimodal data (image/audio, via Base64Source / URLSource)

content 既可以是一个字符串（自动包装成文本块），也可以是一个内容块列表，用于多模态或携带工具调用 / 结果。

content may be a plain string (auto-wrapped as a text block) or a list of content blocks, used for multimodal input or to carry tool calls / results.

✅ 关键要点✅ Key takeaways
  • Msg = 发送者 + role + 内容块列表。Msg = sender + role + a list of content blocks.
  • UserMsg/AssistantMsg/SystemMsg 是工厂函数，不是子类。UserMsg/AssistantMsg/SystemMsg are factory functions, not subclasses.
  • 内容块统一表达文本、思考、工具调用/结果与多模态数据。Content blocks uniformly express text, thinking, tool calls/results and multimodal data.

🧠 小测验🧠 Quiz

关于 UserMsg / AssistantMsg / SystemMsg，哪一项正确？Which statement about UserMsg / AssistantMsg / SystemMsg is correct?
  1. 它们是 Msg 的三个子类，可用 isinstance 区分They are three subclasses of Msg, distinguishable via isinstance
  2. 它们是三种字段互不相同的独立消息类They are three independent message classes with different fields
  3. 它们是工厂函数，都返回同一个 Msg 类，只是 role 不同They are factory functions that all return the same Msg class, differing only in role
答案与解析Answer & explanation
它们是工厂函数，都返回同一个 Msg 类，只是 role 不同They are factory functions that all return the same Msg class, differing only in role
三者都是工厂函数，返回的都是同一个 Msg（仅 role 不同），不是子类——isinstance(m, UserMsg) 并不成立。
All three are factory functions returning the same Msg (only role differs), not subclasses — isinstance(m, UserMsg) would not work.
