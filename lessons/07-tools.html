工具 ToolsTools

工具（Tool）是 agent 的「手」。Toolkit 负责注册和管理工具，并自动从函数签名 / 文档字符串生成 JSON schema，让模型知道有哪些工具可用、怎么调用。

Tools are the agent's "hands". Toolkit registers and manages tools and auto-generates a JSON schema from each tool's signature / docstring, so the model knows what's available and how to call it.

🧩 生活类比🧩 Analogy
像给助手配一套工具箱：每件工具都贴有「说明标签」（schema）。你只管把工具放进箱子（Toolkit），助手自己读标签决定用哪个。
Like giving an assistant a toolbox: each tool has a "label" (schema). You just put tools in the box (Toolkit) and the assistant reads the labels to pick the right one.

1一个 Python 函数如何变成工具？How does a Python function become a tool? 点击展开expand

FunctionTool 包装一个普通函数：它从函数签名推断参数 schema，从文档字符串提取描述。于是模型看到的「工具说明」就是你函数的签名 + docstring——所以写清楚类型注解和 docstring 很重要。

FunctionTool wraps a plain function: it infers the parameter schema from the function's signature and the description from its docstring. So the "tool spec" the model sees is your function's signature + docstring — which is why clear type hints and docstrings matter.

Agent 内部通过 Toolkit.get_tool_schemas()（异步）取得所有工具的 JSON schema 交给模型；模型选定后由 Toolkit.call_tool(...) 执行。

Internally the agent obtains every tool's JSON schema via Toolkit.get_tool_schemas() (async) and hands it to the model; once the model chooses, Toolkit.call_tool(...) runs it.
