AgentScope 是什么What is AgentScope

AgentScope 2.0 是一个生产级、易用的多智能体（multi-agent）框架。它不替你训练模型，而是把模型的推理与工具使用能力接进真实应用——并顺应越来越强的 agentic LLM，用事件驱动的方式编排「推理-行动」循环。

AgentScope 2.0 is a production-ready, easy-to-use multi-agent framework. It doesn't train models for you; it wires a model's reasoning and tool-use abilities into real applications — leaning into increasingly agentic LLMs with an event-driven reasoning-acting loop.

🧩 生活类比🧩 Analogy
把大语言模型想象成一台很强但很孤立的发动机：它能输出文字，却看不到你的数据库、不会自己调用工具、也不知道何时该停下来。AgentScope 就是那套传动系统 + 仪表盘 + 配件接口，把这台发动机接到工具、权限、工作区，并把整个过程通过仪表盘（事件流）实时显示出来。
Picture an LLM as a powerful but isolated engine: it emits text, but it can't see your database, can't call tools by itself, and doesn't know when to stop. AgentScope is the drivetrain + dashboard + connectors that bolt that engine to tools, permissions and a workspace — and surface the whole process live through a dashboard (the event stream).

传统的 response = call(prompt) 只能在全部算完后拿到结果。但一个 agent 可能要思考、调用多个工具、流式吐字——前端希望边发生边显示，人类也可能需要在中途批准某次工具调用。事件流把这些中间状态都暴露出来。

A traditional response = call(prompt) only hands you a result after everything finishes. But an agent may think, call several tools, and stream tokens — a UI wants to show progress as it happens, and a human may need to approve a tool call mid-flight. The event stream exposes all of those intermediate states.

💡 设计亮点💡 Design highlight
设计哲学：不用死板的提示词和编排去约束模型，而是放大它本身的推理与工具使用能力。模型越强，框架越省力——这正是「为 agentic LLM 设计」的含义。
Design philosophy: rather than constraining the model with rigid prompts and orchestration, amplify its own reasoning and tool use. The stronger the model, the less the framework fights it — that is what "designed for agentic LLMs" means.
✅ 关键要点✅ Key takeaways
  • AgentScope 负责模型周边的管道，而不是训练模型本身。AgentScope handles the plumbing around the model, not training the model itself.
  • 核心心智模型：Agent = 模型 + 工具 + 系统提示，运行「推理-行动」循环。Core mental model: Agent = model + tools + system prompt, running a reasoning-acting loop.
  • 一切交互通过事件流暴露，天然支持 UI 与人类介入（human-in-the-loop）。All interaction is exposed via an event stream, naturally supporting UIs and human-in-the-loop.
