Agent ServiceAgent Service

把单个 agent 升级成可部署的服务：create_app(...) 返回一个 FastAPI 应用，内置多租户、多会话隔离，并把 agent 的事件流接到前端。

Turn a single agent into a deployable service: create_app(...) returns a FastAPI app with built-in multi-tenancy and multi-session isolation, wiring the agent's event stream to a frontend.

🧩 生活类比🧩 Analogy
前面几课像在自家厨房做菜；本课是开一家餐厅：要同时接待很多客人（多租户）、每桌各点各的（多会话），还要有前台、传菜和后厨调度。
Earlier lessons were cooking in your own kitchen; this one opens a restaurant: serve many guests at once (multi-tenancy), each table with its own orders (multi-session), plus a front desk, runners and kitchen dispatch.

create_app

create_app

create_app 需要三个基础设施后端：存储（会话/状态持久化）、消息总线（事件分发，见下一课）、工作区管理器（为每个会话提供隔离的执行环境）。其余都是可选扩展点。

create_app takes three infrastructure backends: storage (session/state persistence), a message bus (event dispatch — next lesson), and a workspace manager (an isolated execution environment per session). Everything else is an optional extension point.

1挂载到已有的 FastAPI 应用Mounting onto an existing FastAPI app 点击展开expand

可选参数支持注入：额外凭证类型、FastAPI 中间件、每个 agent 的中间件与工具、自定义 agent 类，以及子代理模板（SubAgentTemplate，供 Agent Team 使用，见第 25 课）。

Optional parameters let you inject: extra credential types, FastAPI middlewares, per-agent middlewares and tools, a custom agent class, and sub-agent templates (SubAgentTemplate, used by Agent Team — lesson 25).

⚠️ 重要⚠️ Important
运行前置条件：服务自带的 storage 与 message_bus 实现是 Redis-only（只有 workspace 有本地实现）。需要先跑起 Redis（如 docker run -p 6379:6379 redis:7），安装 agentscope[full]，后端从 agentscope.app.storage / .message_bus / .workspace_manager 导入；Web UI（examples/web_ui）需 Node ≥ 20。
Runtime prerequisites: the shipped storage and message_bus implementations are Redis-only (only the workspace has a local backend). Run Redis first (e.g. docker run -p 6379:6379 redis:7), install agentscope[full], and import the backends from agentscope.app.storage / .message_bus / .workspace_manager; the Web UI (examples/web_ui) needs Node ≥ 20.
💡 设计亮点💡 Design highlight
三大后端都是统一接口：工作区已有本地/Docker/E2B 多种实现，存储与消息总线目前只有 Redis 实现——接口留出了扩展空间，未来可接入更多后端。
All three backends sit behind uniform interfaces: the workspace already has local/Docker/E2B implementations, while storage and the message bus ship only Redis today — the interfaces leave room to plug in more backends later.
✅ 关键要点✅ Key takeaways
  • create_app 返回标准 FastAPI 应用，可独立运行或挂载。create_app returns a standard FastAPI app you can run standalone or mount.
  • 三大后端：storage · message_bus · workspace_manager。Three backends: storage · message_bus · workspace_manager.
  • 多租户 + 多会话隔离是内置能力。Multi-tenancy + multi-session isolation are built in.

答案与解析Answer & explanation
storage 与 message_bus 目前只有 Redis 实现，只有 workspace_manager 有本地后端storage and message_bus ship Redis-only today; only workspace_manager has a local backend
三大后端（storage / message_bus / workspace_manager）都是统一接口，但 storage 与 message_bus 目前只发布了 Redis 实现，运行前需先启动 Redis；只有 workspace 有本地 / Docker / E2B 等实现。
The three backends (storage / message_bus / workspace_manager) sit behind uniform interfaces, but storage and the message bus ship Redis-only today, so you must start Redis first; only the workspace has local / Docker / E2B implementations.
