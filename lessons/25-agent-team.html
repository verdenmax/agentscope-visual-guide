Agent TeamAgent Team

Agent Team 让一个领导 agent 动态创建并协调多个工作 agent：通过内置的「团队工具」生成队员、分派任务、汇集结果。

Agent Team lets a leader agent dynamically spawn and coordinate worker agents: it creates teammates, hands out tasks and gathers results through built-in "team tools".

🧩 生活类比🧩 Analogy
像一位项目负责人：自己不写全部代码，而是按需招募「研究员」「程序员」等角色（按模板），分配任务、互相沟通，最后汇总交付。
Like a project lead: instead of doing everything alone, they recruit roles like "researcher" or "coder" on demand (from templates), assign tasks, communicate, and assemble the final delivery.

SubAgentTemplate：队员蓝图

SubAgentTemplate: the worker blueprint

你在 create_app(custom_subagent_templates=[...]) 处注册若干 SubAgentTemplate。每个模板的 type 字段（如 'researcher'）会成为 AgentCreate 工具里 subagent_type 参数的一个可选值，description 则告诉模型该类型适合干什么。

You register SubAgentTemplates at create_app(custom_subagent_templates=[...]). Each template's type field (e.g. 'researcher') becomes an allowed value of the subagent_type parameter in the AgentCreate tool, and description tells the model what that type is good for.

1领导与队员如何协作？How do leader and workers collaborate? 点击展开expand

领导 agent 调用 AgentCreate(subagent_type="researcher", name="r1") 生成一个队员，再用 TeamSay(to="r1", ...) 分派任务；队员完成后把结果回传，领导汇总。整个过程仍以事件流对外播报，前端可见每个队员的进展。

The leader calls AgentCreate(subagent_type="researcher", name="r1") to spawn a worker, then TeamSay(to="r1", ...) to assign work; the worker returns its result and the leader aggregates. The whole process is still narrated over the event stream, so a frontend sees each worker's progress.

💡 设计亮点💡 Design highlight
团队协作不是写死的编排，而是暴露成工具交给领导 agent 自己决定何时招人、分派什么——再次体现「放大模型能力，而非约束它」的设计哲学。
Team collaboration isn't hard-wired orchestration; it's exposed as tools for the leader agent to decide when to recruit and what to delegate — again reflecting "amplify the model, don't constrain it".
✅ 关键要点✅ Key takeaways
  • 领导 agent 用团队工具（TeamCreate/AgentCreate/TeamSay）动态组队。The leader uses team tools (TeamCreate/AgentCreate/TeamSay) to form a team on the fly.
  • SubAgentTemplate 是队员蓝图，在 create_app 处注册。SubAgentTemplate is the worker blueprint, registered at create_app.
  • 协作过程仍走统一事件流，全程可观测。Collaboration still flows over the unified, observable event stream.
