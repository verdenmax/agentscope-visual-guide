整体架构全景Architecture panorama

AgentScope 由一组职责清晰、可独立理解的模块组成。先建立这张「全景地图」，后面每一课都能对号入座。

AgentScope is built from a set of clearly-scoped, independently understandable modules. Build this panorama first and every later lesson will slot neatly into place.

🧩 生活类比🧩 Analogy
把它想成一间智能工坊：模型是「大脑」，工具是「手」，权限是「门禁」，工作区是「车间」，事件流是「监控大屏」，而服务层（app）是「前台与调度室」。
Think of it as a smart workshop: the model is the brain, tools are the hands, permissions are the door access, the workspace is the shop floor, the event stream is the monitoring wall, and the service layer (app) is the front desk and dispatch room.

它们如何协作

How they fit together

一次调用里，agent 居中调度，按这个顺序串起其余模块：

In a single call, the agent coordinates, threading the other modules in this order:

1
推理 ReasonReason
用 credential 配好的 model 思考下一步。think with a model configured via credential.
2
格式化 FormatFormat
把对话历史交给 formatter 转成厂商请求格式。hand the dialogue history to a formatter for the vendor's format.
3
行动 ActAct
需要时调用 tool——受 permission 把关，可在 workspace 中执行。call tools when needed — gated by permission, run in a workspace.
4
播报 BroadcastBroadcast
整个过程由 event 流向外播报，并可被 middleware 拦截增强。broadcast the whole process over the event stream, interceptable by middleware.
🔬 源码对应🔬 Source mapping
agent/__init__.pyAgent 与配置类的入口entry for Agent and its config classes
model/__init__.py模型抽象与厂商实现的入口entry for the model abstraction and vendor implementations
tool/__init__.pyToolkit 与工具体系的入口entry for Toolkit and the tool system
app/__init__.pycreate_app 服务入口the create_app service entry
✅ 关键要点✅ Key takeaways
  • 模块边界清晰：每个模块都能单独理解、单独替换。Boundaries are clear: each module can be understood and replaced independently.
  • agent 是中枢，其余模块围绕它提供能力。The agent is the hub; the other modules provide capabilities around it.
  • app 层把单个 agent 升级成可部署的多租户服务。The app layer turns a single agent into a deployable multi-tenant service.

🧠 小测验🧠 Quiz

在一次回复中，哪个模块居中调度、把 model / formatter / tool / event 串起来？During one reply, which module sits at the center and threads together model / formatter / tool / event?
  1. app（服务层）app (the service layer)
  2. middlewaremiddleware
  3. agentagent
答案与解析Answer & explanation
agentagent
agent 是中枢，按「推理→格式化→行动→播报」串起其余模块。app 只是把 agent 包装成多租户服务，middleware 只是围绕循环的钩子。
The agent is the hub, threading the others as reason→format→act→broadcast. app merely wraps agents into a multi-tenant service, and middleware only hooks around the loop.
