工作区 & 沙箱Workspace & Sandbox

工作区（Workspace）是 agent 执行工具/代码的隔离环境。WorkspaceBase 抽象出统一接口，内置本地、Docker、E2B 三种后端；Offloader 负责把超长上下文 / 工具结果卸载出去。

A Workspace is the isolated environment where an agent runs tools/code. WorkspaceBase abstracts a unified interface with built-in local, Docker and E2B backends; an Offloader offloads oversized context / tool results.

🧩 生活类比🧩 Analogy
像给实习生一间独立车间而不是让他在你的主控室乱动：本地车间最快，Docker 车间更隔离，E2B 是云端租来的车间。
Like giving an intern a separate workshop instead of letting them loose in your control room: the local one is fastest, Docker is more isolated, and E2B is a rented cloud workshop.

1Offloader 解决什么？What does the Offloader solve? 点击展开expand

长对话和大工具结果会撑爆上下文窗口。Offloader 把压缩后的上下文与被截断的工具结果卸载到工作区（如写入文件），需要时再取回——在「带得动」和「不丢信息」之间取得平衡。

Long conversations and large tool results blow up the context window. The Offloader offloads compressed context and truncated tool results to the workspace (e.g. to files), fetching them back when needed — balancing "fits in the window" against "loses no info".

  • 工作区为工具/代码执行提供隔离环境。A workspace provides an isolated environment for tool/code execution.

🧠 小测验🧠 Quiz

Offloader 在工作区里解决什么问题？What problem does the Offloader solve in a workspace?
  1. 把超长上下文 / 大工具结果卸载到工作区（如写入文件），需要时再取回，避免撑爆上下文窗口It offloads oversized context / large tool results to the workspace (e.g. to files) and fetches them back when needed, so the context window doesn't overflow
  2. 它对每次工具调用作出放行 / 拒绝 / 需确认的裁决It renders an allow / deny / needs-confirm decision for each tool call
  3. 它在多台机器间做负载均衡，把任务分发出去It load-balances tasks by distributing them across multiple machines
答案与解析Answer & explanation

The Offloader offloads oversized context and truncated tool results and fetches them back; allow/deny is the permission engine's job (lesson 16).
