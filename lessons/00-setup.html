🧠 小测验🧠 Quiz

第一个程序为什么写成 async def main() + await agent.reply(...) + asyncio.run(main())？Why is the first program written as async def main() + await agent.reply(...) + asyncio.run(main())?
  1. 因为 AgentScope 的 API 是异步的：reply(...) 返回协程，必须 await 并由事件循环驱动Because AgentScope's API is async: reply(...) returns a coroutine that must be awaited and driven by an event loop
  2. 异步只是为了让这一次调用返回得更快Async is only there to make this single call return faster
  3. 因为模型默认流式输出，不用 asyncio 就拿不到完整回复Because the model streams by default, and without asyncio you can't get the full reply
答案与解析Answer & explanation
因为 AgentScope 的 API 是异步的：reply(...) 返回协程，必须 await 并由事件循环驱动Because AgentScope's API is async: reply(...) returns a coroutine that must be awaited and driven by an event loop
AgentScope 全程异步：reply 是协程、reply_stream 是异步生成器，都得 await / async for，所以入口用 asyncio.run。这与「更快」或「流式」无关——reply 本身就返回完整的 AssistantMsg。
AgentScope is async throughout: reply is a coroutine and reply_stream an async generator, both needing await / async for — hence asyncio.run at the entry. It is not about speed or streaming; reply already returns the complete AssistantMsg.
