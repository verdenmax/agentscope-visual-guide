Toolkit 内部Toolkit Internals

Toolkit 内部做三件事：把注册的工具转成 JSON schema 给模型、在模型选定后执行对应工具、并支持分组管理（动态启用/停用）。

Internally, Toolkit does three things: turn registered tools into JSON schemas for the model, execute the chosen tool, and support group-wise management (dynamic enable/disable).

🧩 生活类比🧩 Analogy
像一个带标签系统的工具柜：能列出每件工具的说明卡（schema），按编号取用（call），还能按抽屉分组、临时锁住某些抽屉（tool group）。
Like a labeled tool cabinet: it can list each tool's spec card (schema), fetch one by number (call), and group tools into drawers it can temporarily lock (tool group).

分组与适配器

Groups and adapters

ToolGroup 让你把工具分组、并在运行时启用/停用整组——例如先只开放「只读」工具，确认后再开放「写」工具。FunctionTool 适配普通函数，MCPTool 适配来自 MCP 服务器的工具（第 18 课）。

ToolGroup lets you group tools and enable/disable a whole group at runtime — e.g. expose only "read-only" tools first, then "write" tools after confirmation. FunctionTool adapts plain functions and MCPTool adapts tools from an MCP server (lesson 18).

工具分组让你按需暴露能力：把工具归入 ToolGroup，运行时只激活需要的组——例如先只给「只读」组，确认后再激活「写」组，从而缩小模型一次能用的工具面。

Tool groups let you expose capabilities on demand: put tools into a ToolGroup and activate only the groups you need at runtime — e.g. expose a "read-only" group first and activate a "write" group after confirmation, shrinking the tool surface the model sees at once.

🧠 小测验🧠 Quiz

一个工具明明已注册进 Toolkit，模型却「看不到」、用不了。最可能的原因是？A tool is registered in the Toolkit, yet the model can't “see” or use it. The most likely reason?
  1. 它所在的 ToolGroup 当前未激活——分组的「启用/停用」把它挡在了模型可见列表之外Its ToolGroup is currently inactive — the group enable/disable mechanism keeps it out of the list the model sees
  2. 必须重启进程，注册的工具才会对模型生效You must restart the process before registered tools take effect
  3. get_tool_schemas 默认隐藏所有工具，需手动逐个开启get_tool_schemas hides all tools by default; you enable them one by one
答案与解析Answer & explanation
它所在的 ToolGroup 当前未激活——分组的「启用/停用」把它挡在了模型可见列表之外Its ToolGroup is currently inactive — the group enable/disable mechanism keeps it out of the list the model sees
Toolkit 支持按 ToolGroup 分组并在运行时启用/停用：未激活分组里的工具不会出现在 get_tool_schemas 给模型的清单里（强行调用会触发 ToolGroupInactiveError）。
The Toolkit groups tools into ToolGroups that can be enabled/disabled at runtime: tools in an inactive group don't appear in the list get_tool_schemas hands the model (calling one anyway raises ToolGroupInactiveError).
