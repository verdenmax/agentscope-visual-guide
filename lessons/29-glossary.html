This is a bilingual quick-reference: the left column lists real AgentScope 2.0 symbols (classes / functions / enums / type aliases), the middle gives a one-line definition, and the right links to the lesson that first explains it in depth. Use your browser's Ctrl/Cmd+F to jump to a term, or the language toggle (top-right) to switch languages.

📌 注意📌 Note
表中部分条目并非类：UserMsg / AssistantMsg / SystemMsg 是返回 Msg 的工厂函数，ContentBlock 是一个类型别名（各内容块的联合），create_app 是函数，而 ReAct loop 是一个概念（由 Agent 与 ReActConfig 落地）。
A few entries aren't classes: UserMsg / AssistantMsg / SystemMsg are factory functions returning a Msg, ContentBlock is a type alias (the union of content blocks), create_app is a function, and ReAct loop is a concept (realized by Agent and ReActConfig).

🧠 小测验🧠 Quiz

下列哪一项不是类，而是返回 Msg 的工厂函数？Which of these is not a class, but a factory function that returns a Msg?
  1. UserMsgUserMsg
  2. Msg（消息核心类本身）Msg (the core message class itself)
  3. ContentBlockContentBlock
答案与解析Answer & explanation
UserMsgUserMsg
UserMsg / AssistantMsg / SystemMsg 是工厂函数，按固定 role 构造一个 Msg；Msg 是它们返回的核心类，而 ContentBlock 既不是类也不是工厂，而是各内容块类型的联合（类型别名）。
UserMsg / AssistantMsg / SystemMsg are factory functions that build a Msg with a fixed role; Msg is the core class they return, while ContentBlock is neither a class nor a factory but a type alias (the union of content-block types).
FormatterBase 的职责是什么？What is the responsibility of FormatterBase?
  1. 把 Msg 列表转换成各厂商要求的请求格式Turn a Msg list into each vendor's request format
  2. 管理 API key 与密钥Manage API keys and secrets
  3. 在沙箱中执行工具Execute tools inside a sandbox
答案与解析Answer & explanation
把 Msg 列表转换成各厂商要求的请求格式Turn a Msg list into each vendor's request format
FormatterBase 负责把统一的 Msg 列表适配成不同厂商的具体请求格式；管理密钥的是 CredentialBase，沙箱执行属于 WorkspaceBase。
FormatterBase adapts the unified Msg list into each vendor's concrete request format; secrets are handled by CredentialBase and sandboxed execution by WorkspaceBase.
