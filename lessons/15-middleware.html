中间件系统Middleware

中间件（Middleware）让你在不改 Agent 源码的前提下，在循环的关键阶段插入逻辑：追踪、日志、缓存、改写系统提示、增删工具……

Middleware lets you insert logic at key stages of the loop without editing the Agent's source: tracing, logging, caching, rewriting the system prompt, adding/removing tools…

🧩 生活类比🧩 Analogy
像给函数加装饰器：原函数不变，你在它前后包一层，做记录、改参数或拦截。中间件就是 agent 循环各阶段的装饰器。
Like adding a decorator to a function: the original is untouched, you wrap logic around it to log, tweak arguments, or intercept. Middleware is a decorator for each stage of the agent loop.

钩子点

Hook points

钩子方法Hook method时机When
on_replyon_reply整次回复的最外层the outermost wrap of a whole reply

on_actingon_acting每次行动（执行工具）前后around each acting step (tool execution)

Built-in examples: TracingMiddleware (observability / tracing) and TTSMiddleware (pipe text replies into speech synthesis, lesson 22). Writing your own: lesson 27.

💡 设计亮点💡 Design highlight
中间件把「横切关注点」（日志/追踪/限流/改写）从 agent 主逻辑里剥离出来——主循环保持干净，扩展点保持可组合。
Middleware peels "cross-cutting concerns" (logging/tracing/throttling/rewriting) out of the agent's main logic — the loop stays clean and the extension points stay composable.
✅ 关键要点✅ Key takeaways
  • 中间件在循环各阶段插入逻辑，不改 Agent 源码。Middleware inserts logic at loop stages without editing Agent source.
  • 钩子：on_reply/on_reasoning/on_acting/on_model_call/on_system_prompt 等。Hooks: on_reply/on_reasoning/on_acting/on_model_call/on_system_prompt, etc.
  • 通过 Agent(middlewares=[...]) 挂载。Attach via Agent(middlewares=[...]).
