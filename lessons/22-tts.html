TTS 语音TTS

TTS（文本转语音）把 agent 的文字回复变成声音。TTSModelBase 定义统一接口（含实时模式），TTSMiddleware 把它接进 agent 的回复流。

TTS (text-to-speech) turns an agent's text replies into audio. TTSModelBase defines a unified interface (including a realtime mode), and TTSMiddleware wires it into the agent's reply flow.

🧩 生活类比🧩 Analogy
像给文字配一位配音演员：模型负责写台词，TTS 负责念出来；实时模式则像「边写边念」。
Like giving the text a voice actor: the model writes the lines and TTS speaks them; realtime mode is like "speaking as it's written".

1实时 TTS 的工作方式How realtime TTS works 点击展开expand

TTSModelBase 是一个异步上下文管理器：先 connect() 建立会话，随着模型不断吐字，用 push(text) 把增量文本送进去，底层边收边合成音频，最后 close()。一次性的 synthesize() 则是把整段文本一口气合成。

TTSModelBase is an async context manager: connect() opens a session, then as the model streams text you push(text) the increments and the backend synthesizes audio as it arrives, ending with close(). The one-shot synthesize() instead renders the whole text at once.

💡 提示💡 Tip
按延迟需求选型：做语音助手 / 实时对话用 DashScopeRealtimeTTSModel（首字更快、可打断）；批量生成音频文件用 DashScopeTTSModel 即可。无论哪种，都通过 TTSMiddleware 接入，不动 agent 主逻辑。
Choose by latency: for a voice assistant / live dialogue use DashScopeRealtimeTTSModel (faster first sound, interruptible); for batch audio files DashScopeTTSModel is fine. Either way you wire it via TTSMiddleware without touching the agent's core logic.

🧠 小测验🧠 Quiz

想要「边生成边出声」的低延迟语音，应选用哪种 TTS 模型？For low-latency “speak as it's generated” audio, which TTS model should you use?
  1. DashScopeRealtimeTTSModel（实时流式合成）DashScopeRealtimeTTSModel (realtime streaming synthesis)
  2. DashScopeTTSModel（等整段文本就绪后一次性合成）DashScopeTTSModel (one-shot synthesis after the full text is ready)
  3. TTSMiddleware，它本身就是一个能直接发声的模型TTSMiddleware, which is itself a model that produces audio
答案与解析Answer & explanation
DashScopeRealtimeTTSModel（实时流式合成）DashScopeRealtimeTTSModel (realtime streaming synthesis)
低延迟流式用 DashScopeRealtimeTTSModel，整段一次性合成用 DashScopeTTSModel；TTSMiddleware 只是把所选 TTS 模型接进回复流的中间件，本身不合成。
Use DashScopeRealtimeTTSModel for low-latency streaming and DashScopeTTSModel for one-shot; TTSMiddleware is just the wiring that pipes a chosen TTS model into the reply flow, not a synthesizer.
