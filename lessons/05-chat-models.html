聊天模型Chat Models

聊天模型是 agent 的「大脑」。所有厂商实现都继承 ChatModelBase，暴露统一接口；调用返回一个 ChatResponse（含内容块与用量）。

The chat model is the agent's "brain". Every vendor implementation subclasses ChatModelBase and exposes a unified interface; a call returns a ChatResponse (content blocks + usage).

🧩 生活类比🧩 Analogy
像一个万能遥控器：不管电视是哪个牌子，按钮都一样。换模型 = 换一个ChatModelBase 子类，调用代码几乎不动。
Like a universal remote: whatever the TV brand, the buttons are the same. Swapping models = swapping a ChatModelBase subclass, with almost no change to calling code.

1ChatResponse 里有什么？What's in a ChatResponse? 点击展开expand

ChatResponse 携带模型产出的内容块（文本/思考/工具调用）与 ChatUsage（token 用量）。需要结构化输出时用 StructuredResponse。ModelCard 描述模型能力元信息。

ChatResponse carries the model's content blocks (text/thinking/tool calls) plus ChatUsage (token usage). For structured output use StructuredResponse; ModelCard describes a model's capability metadata.

💡 提示💡 Tip
生产可靠性：通过 Agent(model_config=ModelConfig(max_retries=2, fallback_model=backup)) 配置重试与降级到备用模型，无需改业务代码。
Production reliability: configure retries and a fallback model via Agent(model_config=ModelConfig(max_retries=2, fallback_model=backup)) — no business-code change.
